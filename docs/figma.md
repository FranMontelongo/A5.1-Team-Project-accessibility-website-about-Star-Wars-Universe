# Guía para Figma — Francisco Javier coordina

1. Crea una página de Figma llamada `Star Wars accesible`.
2. Crea frames de escritorio (por ejemplo 1440 px) y móvil (por ejemplo 390 px).
3. Diseña los componentes: navegación, botón principal, tarjeta de personaje, reproductor multimedia y pie.
4. Define colores y tipografía y comprueba el contraste antes de pasarlos a CSS.
5. Usa Auto Layout en tarjetas y navegación, componentes reutilizables y prototipo navegable.
6. Incluye estados de foco/hover y una versión móvil.
7. Exporta capturas del diseño final para la presentación.
8. No copies imágenes con copyright sin permiso: usa recursos permitidos y guarda su fuente/licencia.
